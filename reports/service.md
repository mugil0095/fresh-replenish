# Service

The nightly batch job (`uv run python -m fresh_replenish.serving.batch`) trains LightGBM on recovered demand, calibrates its deciles and writes cost-based orders for every series for the next week; each run is tracked in MLflow. The API (`uv run uvicorn --factory fresh_replenish.serving.api:create_app`) serves one store's orders per request, and turns one store's midday shelf count into top-up units. Latency is measured over HTTP on this laptop, one request at a time. Generated by `uv run python -m fresh_replenish.serving.latency`.

## Headline

- **Batch:** 50,000 series and 350,000 order lines in 13.3 minutes (as of 2024-06-25).

- **API:** p95 latency 14.7 ms per store request (p50 8.8 ms, 500 requests).

- **Top-up:** p95 latency 12.3 ms for a whole store's shelf count (p50 8.9 ms, 500 requests).
