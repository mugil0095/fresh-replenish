# Service

The nightly batch job (`uv run python -m fresh_replenish.serving.batch`) trains LightGBM on recovered demand, calibrates its deciles and writes cost-based orders for every series for the next week; each run is tracked in MLflow. The API (`uv run uvicorn --factory fresh_replenish.serving.api:create_app`) serves one store's orders per request. Latency is measured over HTTP on this laptop, one request at a time. Generated by `uv run python -m fresh_replenish.serving.latency`.

## Headline

- **Batch:** 50,000 series and 350,000 order lines in 11.5 minutes (as of 2024-06-25).

- **API:** p95 latency 7.3 ms per store request (p50 5.1 ms, 500 requests).
